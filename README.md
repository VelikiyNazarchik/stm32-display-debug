# STM32 Basics: Display & Hardware Debugging

## Опис проєкту
Мініпроєкт, реалізований для практичного занурення в архітектуру та екосистему промислових мікроконтролерів сімейства STM32. Головною метою було налаштування базової конфігурації, з периферією та використання інструментів налагодження.

## Апаратна база
* **Мікроконтролер:** STM32
* **Дебагер:** ST-Link
* **Периферія:** OLED дисплей 0.96" I2C

## Що було реалізовано
Налаштування GPIO, увімкнення HSE, налаштування частоти HCLK на 250МГц, а також налаштування шини I2C для роботи з OLED-дисплеєм. Практичне використання модифікованого ST-Link для апаратного налагодження та дебагу за допомогою Trace Asynchronous Sw.
