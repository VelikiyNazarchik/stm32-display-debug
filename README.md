# STM32 Basics: Display & Hardware Debugging

## Опис проєкту
Мініпроєкт, створений для практичного занурення в архітектуру промислових мікроконтролерів сімейства STM32. Головна мета - налаштування екосистеми, робота з периферією та використання апаратного дебагера.

## Апаратна база
* **Мікроконтролер:** STM32 [тут впиши точну модель, наприклад STM32F103C8T6 "Blue Pill"]
* **Програматор/Дебагер:** ST-Link [наприклад, V2]
* **Периферія:** [Вкажи модель дисплея, наприклад I2C OLED 0.96" або LCD 1602]

## Що було реалізовано
* **Конфігурація системи:** Базове налаштування тактування мікроконтролера та ініціалізація портів вводу/виводу.
* **Робота з периферією:** Налаштування шини даних [I2C або SPI - вкажи правильне] та успішний вивід тестової інформації на LED-дисплей.
* **Апаратне налагодження:** Підключення ST-Link для внутрішньосхемного налагодження (In-Circuit Debugging). Практичне використання точок зупину (breakpoints), покрокового виконання коду та моніторингу регістрів/змінних у реальному часі.
